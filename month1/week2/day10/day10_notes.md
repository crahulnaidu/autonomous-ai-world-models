# Day 10

## MLP Architecture
It consists of a stack of layers each containing neurons connected to each other via activations.

## Dense Layers
They are the layers with the most number of neurons.

## Forward Propagation
It is the flow of input through a MLP in the forward direction in which the input is multiplies with the weights of each layer and then an activation function is applied at each layer.

## Tensor Dimensions
MLP is essentially weights and activations.So when a tensor flows through an MLP,its dimension at each layer depends on the number of neurons in the previous and current layer.

## Bias
A term added to the weighed sum in a neuron to make it more expressible.

## Computational Graphs
They are graphs that show the flow of operands and data through an expression.

## Hidden Representations
They are the outputs of hidden layers after the activation function is applied.

## Quantum Forward Process
It is a forward and continuous application of unitary gates to a qubit.

## AI Hardware
Since matrix multiplication is the primary operation in MLP,hardware built for MLP must optimize it.
