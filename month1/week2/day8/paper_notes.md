# Rosenblatt (1958)

## Motivation
To understand how biological organisms store and process stimulii.

## Main Idea
The main idea was introducing a logic unit called perceptron that takes in inputs and applies an activation function.

## Key Contributions
A perceptron can be trained like a regression or classification model using gradient descent.

## Limitations
Did not work for XOR gate or non-linearly separable data.

## Connection to Modern Deep Learning
Modern deep learning is essentially multiple stacks of layers of perceptrons.
