## Theory.

1.Linear Regression cannot model non-linear decision boundaries that data have.

2.A decision boundary is a hyperplane separating different classes of data.

3.XOR produce's data with non-linear separation.

4.Activation functions are needed to squish values between ranges and to also add non-linearity to model complex relationships within data.

5.Removing all activation functions would make the model a linear function,i.e it would become a linear regression model.
