## Learning vs Optimization 

larning in ML is the process of modifying model parameters to recognize patternsin data and gain insights from it.

Optimization is the actual tweaking of model parameter's to reduce some sort of cost function using back propogation.It is a part of learning.

## Parameters.

They are number's or weight's associated with a model which change during training to learn patterns about input information.

## Feature Scaling.

It is the process of normalizing the range of feature's so that are in similar range.This take's care of ridge's,plateau's in the cost function during gradient descent.

## Batch Gradient Descent.

It is updating the model parameter's using the entire training example's or instances at each step.

## Linear Regression Training.

It involve's fitting a line to input data ,which may have features scaled to power.

## Multiple Qubits.

multiple qubits are represented as a tensor product of individual qubits.

## GPU Matrix Multiplication.

A gpu optimize's matrix multiplication using massive parallelism,fast on chip memory and memory bandwidth.
