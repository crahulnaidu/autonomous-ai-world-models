## AI vs ML vs DL vs RL

AI is the field of teaching machine's to think and perform tasks like a human 
being.

ML is the subset of AI and deals with making machine's understand patterns and insights from data using algorithm's.

DL is the subset of ML in which a model is trained to recognize patterns and make inferences on it based on a deep sequence of layers each composed of artificial neuron's inspired from the human brain.

RL is another subset of ML which involve's an agent,environment interaction.Here an agent learn's to perform some optimal set of actions based on the reward generated and the criteria to achieve a goal.No explicit instructions are given to the agent,it learns to interact with the environment and achieve it's goals based on trial and error.


## Training vs Inference

Training involve's tuning a model's parameters to reduce some sort of loss function or to make the model learn about the data.

Inference is the model making decision's based on it's trained parameter's on new data it has not seen before.


## What is a Model?

A model is essentially a function that fits a curve on the input data and use's it to predict the output of new data.

## CPU vs GPU

A CPU handle's few but complex instruction's ,it is built for performing complex tasks like file creation and handling along with basic arithmetic.
A GPU perform's simple operation's at a large scale.It is used to train AI model's as it is optimized for vector operations like multiplication heavily used during training.
