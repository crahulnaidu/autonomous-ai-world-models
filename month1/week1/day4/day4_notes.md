## Objective Function

It is a mathematical function that tells how good or bad a model is.

## Optimization

It is the tuning of parameter's of a model to reduce a certain cost function.

## Convex Functions

They are functions such that any 2 points on the curve when joined by a straight line does not touch the curve.They have an absolute global minimum.

## Local Minimum.

It is a point in a function where the first derivative is zero and the second derivate is >0 for an epsilon neighborhood around the point.

## Global Minimum

It is the point x* in a function such that f(x*)<=f(x) ,i.e the value of the function at that point is lesser than every other value all over the function.

## Saddle point.

It is a point in the function such that the value's in the hessian matrix are both positive and negative.

## Gradient.

It is it the direction of steepest ascent for multivariate-functions.

## Bell States.

They are a set of orthonormal states that form the basis of all 2 qubit quantum states.Each one is entangled.

## Floating point precision.

neural networks use floating point's so that the loss function is a smooth curve and so that the gradient is more stable.
